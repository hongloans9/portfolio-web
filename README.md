# Personal Portfolio

Live: [hongloans9.github.io/portfolio-web](https://hongloans9.github.io/portfolio-web/)

## Tech Stack

- [React 18](https://reactjs.org/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Chakra UI v2](https://chakra-ui.com/)
- [Framer Motion](https://www.framer.com/motion/)

## Getting Started

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173/portfolio-web/`

## Deploy

```bash
npm run deploy
```

Builds and publishes to GitHub Pages via the `gh-pages` branch.
